# The projects whose code the phone app includes, with their licences: the list its screen "Open-source licences"
# shows, in this order. The build puts each licence's text beside this file, as licences/<id>.txt (the task
# licenceTexts in app/build.gradle.kts), and its check checkLicences, which `check` runs, fails unless each module
# of the release build's runtime classpath is covered by exactly one project here, each covers line covers one, and
# each includes line names a file or folder that is there. A module that comes in with a new or updated library is
# added to its project, or a project is added for it, with the licence its .pom (or its jar) names; a file copied
# into the app's source from a project that is not a library is added to that project's includes.
#
# A paragraph is a licence or a project, a line each of a key and its value:
#
#   licence ID        a licence, by the id the projects name it by, which is also its text's file name;
#   title TITLE       its name, as the screen shows it.
#
#   project NAME      a project, by its name as the screen shows it;
#   licence ID        its licence;
#   covers GROUP      a Maven group it covers, one a line, or GROUP:NAME where the group is not all its own;
#   includes PATH     a file of the app's source that is the project's and not a library's, or a folder of them,
#                     one a line, as a path from android/app/ such as src/main/res/drawable/ic_add.xml.
#
# A project has at least one covers or includes line, and may have both.
